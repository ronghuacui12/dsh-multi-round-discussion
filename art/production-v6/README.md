十二模型为 ChatGPT、Claude、Gemini、Grok、DeepSeek、GLM、MiniMax、Kimi、Step、MiMo、千问 Qwen、豆包 Doubao。

十一种状态按 `idle / ready / thinking / waiting / done / approval / executing / error / aborted / celebrate / speaking` 排列。前十种对应当前代码的 VisualState，speaking 是补齐的发言姿态。头像为独立第十二格。人物以模型身份区分，换职责不换服装，也不需要按五种职责再复制绘制。

本轮新生成了十二张人物图集和五张家具/摆件源图，可拆成 149 个独立素材；另外三个独立素材——房间、短桌、长桌——沿用上一轮已通过内置生图生成的选定源图。**没有拿同一张人物图改名冒充多个状态。** 共保存 20 张选定源图。

## 目录

- `sources/`：20 张原始选定生图，人物每张 4 × 3 格。
- `png/characters/<模型>/<状态>.png`：132 张透明人物状态图。
- `png/portraits/<模型>.png`：12 张透明头像。
- `png/scene/`：8 件场景资源，房间不透明，其余透明。
- `webp/`：与 PNG 一一对应的轻量版本。
- `review/overview.png`：模型与场景素材总览。
- `review/all-states.png`：144 件人物素材状态矩阵。
- `review/scene-3.png`、`scene-6.png`、`scene-12.png`：用真实独立素材拼合的审阅图，不是应用截图。
- `manifest.json`：每个文件的尺寸、锚点、源图裁切范围和缩放值。
- `exact-prompts.json`：本轮实际使用的完整人物及摆件提示词；前三件沿用素材明确注明未恢复上一轮完整提示词。
- `prompts.json`：统一提示词模板和角色身份说明。
- `generated-sources.json`：仓库内选定源图路径；`original-generator-files.json` 保留工具生成的原始文件名。源图已全部归档，无需作者本机目录。
- `validation.json`：解码、尺寸、透明通道、数量、重复文件和 SHA-256 验证。
- `export-report.json`：304 个导出文件的大小与 SHA-256。

## 交付规格

人物状态与头像为 **512 × 512** 透明画布；状态图统一底部锚点 **(256, 484)**，同一人物十一种状态共用同一缩放倍率。头像独立居中，锚点 (256, 256)。源图实际为 1448 × 1086，单格可见内容约 300–380 像素，512 为统一导出画布，不声称原生 512 或 4K 细节。

源图的头发、鞋尖可能越过名义等分格，导出采用沿透明空隙的分界，避免固定方格直接切掉头饰或混进邻格。仅作切图、透明边缘杂点整理和尺寸归一，未用代码替代生图绘制人物。

房间为 2172 × 724；长短桌宽 2048，保留自身宽高比；椅子和四摆件为 768 × 768 透明画布。人物、椅子、桌子、摆件、房间分别交付，可以独立增减、替换、重排。

这是**静态状态姿态包**，不包含逐帧口型、骨骼绑定、眨眼逐帧或 PSD/Live2D 源文件。现有呼吸、思考摆动等界面动画可继续作用于这些素材；它们不属于新增绘画件。
