# 持续交互（研讨续接）· 实现说明

日期：2026-10-16 · 对应提交主题：`feat: 研讨续接（同一话题继续追问）`

## 背景

引擎的状态机是「一次研讨一条命」：进入 `completed` / `failed` / `stopped` 之后，`UserInputGate`、`BudgetGuard`、`StateMachine` 都已收摊，run 变成一条只读记录。用户想在同一个话题上继续问一句，过去只能重新发起一条全新的研讨——上下文全丢，等于把讨论重新做一遍。

## 设计选择

**不做**「把终态 run 拉回 `clarifying`」：那需要给终态补 gate / budget / machine，还要和「从磁盘恢复的历史记录保持只读」这条安全规则正面冲突，并且会让同一条 run 的 `startedAt`、成本、轮次含义全部变形。

**做**续接式：

- 新一轮仍是**一条新 run**，生命周期干净，预算、轮次、成本各自独立；
- 宿主把上一轮**已经公开**的结论折成一段上下文块，作为提示词的一部分交给引擎；
- 新 run 记录 `parentRunId`，界面把它画成一条线（可回溯到上一轮）。

只使用 blackboard 上已经公开的内容（问题 / 结论方向 / 最终答复 / 计划步骤 / 执行状态），**不读取任何隐藏推理**；每个字段都有截断上限，避免一次长答复灌进下一轮。

## 改动

| 文件 | 改动 |
|---|---|
| `plugin/lib/plugins/orchestrator.js` | `start()` 接受可选的 `context` 与 `parentRunId`；新增内部字段 `promptRequest`（= 上下文块 + 本轮问题）供引擎使用，而 `state.request` **仍是用户原话**，所以界面气泡显示的就是用户输入的字；`clarify()` 与 `buildPlan()` 两处改用 `promptRequest` |
| `plugin/lib/host/api-routes.js` | `POST /runs` 接受 `parentRunId`：父 run 不存在 → 404；父 run 尚未结束 → 409；`buildContinuationContext()` 负责折叠上下文；`GET /runs` 每条记录附带 `restored` 标记，界面据此区分实时与历史 |
| `plugin/lib/types/run.d.ts` | `RunState` 增加 `parentRunId?` 与 `restored?` |
| `plugin/client-src/chat.tsx` | 终态研讨的输入框占位改为「继续追问这条研讨（会自动带上上一轮结论）…」，按钮改为「继续追问」，发送时自动带 `parentRunId`；顶部出现「↳ 续接：…」可跳回上一轮；历史记录在下拉里带图标前缀 |
| `plugin/lib/client.js` | 重新构建（仍是 `window.__ModuleLoader__.load(...)` 信封，仅 React 外部依赖） |

## 接口

```http
POST /dsh-mmd/runs
{ "request": "那第 2 步能不能换成 Markdown 渲染？", "parentRunId": "mmd-7bdb7460" }
```

- `201` 返回新 run 的 state，其中带 `parentRunId`；
- `404` 父研讨不存在；`409` 父研讨还在进行中（避免两条线抢同一份阵容）。

上下文块形如：

```
【这是一条续接的研讨】下面是上一轮已经完成的结论，本轮是同一话题的追问，不是新话题。
上一轮的问题：……（≤300 字）
上一轮的结论方向：……（≤400 字）
上一轮的最终答复：……（≤800 字）
上一轮的计划：……（最多 6 步）
上一轮的执行：completed（3 步）
本轮要求：直接回答追问；上一轮已经完成并通过验证的步骤不要重复执行；若要改动，给出新的计划并说明与上一轮的差异。
```

## 使用

1. 等一轮研讨进入终态（已完成 / 失败 / 已停止）；
2. 底部输入框变成「继续追问」，直接输入并发送；
3. 顶部「↳ 续接：…」按回上一轮；历史下拉里带图标前缀的是从磁盘恢复的记录。

## 边界

- 续接只带**结论摘要**，不是把整块黑板搬过去；上一轮仍在运行时不允许追问。
- 历史记录上限 300 条（按 `startedAt` 淘汰最旧），由既有的 `RunHistory` 管理。
- 本轮未在运行中的宿主里做端到端实测：宿主缓存 ESM 模块，需完整重启 DSH 后新接口才加载；已完成的是语法检查、12 项单测与仓库两套冒烟回归。
